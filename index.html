Proyeksi penduduk

Pt = P0 × (1 + r100)n
r = laju pertumbuhan (%/tahun), n = selisih tahun

SRT — Pasal 4.2.2

Alt 1 (Pt ≤ 1 jt): Ps = Cd × √Pt
Alt 1 (Pt > 1 jt): Cj = Pt1.000.000 ; Ps = Cd × Cj × √Pt
Alt 2 (Slovin): n = N1 + N·e2
K = PsN̄ ; Nr = Sn × K (per level H/M/L, total disesuaikan = K)

SSSRT — Pasal 4.2.3

Alt 1: S = Cd × √Ts
Alt 2: n = N1 + N·e2
Ts/N = total unit fasilitas sejenis di wilayah; hasil dibatasi Ts

TPS/TPS3R/TPST — Pasal 4.2.4

N > 30/hari → Alt 1: n = N1 + N·e2
N ≤ 30/hari → Alt 2: n = ⌈10% × N⌉

TPA — Pasal 4.2.5

Alt 1: n = N1 + N·e2
Alt 2: n = ⌈10% × N⌉
N = total ritasi alat angkut/hari ke TPA
